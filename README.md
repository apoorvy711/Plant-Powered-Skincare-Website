# 🌿 Plant Powered Skincare Website

A modern and responsive skincare website built using **HTML, CSS, and JavaScript** focused on promoting plant-based and natural skincare products.

This project showcases a clean UI design, responsive layouts, smooth user experience, and visually appealing sections for a skincare brand website.

---

# ✨ Features

- Responsive website design
- Modern skincare landing page
- Smooth navigation
- Product showcase sections
- Hero section with CTA
- Clean and minimal UI
- Mobile-friendly layout
- Interactive frontend elements

---

# 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
